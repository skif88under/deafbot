# Telegram-бот: курьер и сборщик

Бот на Python и aiogram 3 для запуска на BotHost. Код можно хранить в GitHub.

## Возможности

- Выбор вакансии: курьер или сборщик.
- Для курьера доступен выбор Яндекс Еды, Яндекс Лавки и Купера.
- Для сборщика сразу показывается Купер без дополнительных вопросов.
- Тест начинается с выбора вакансии. Для сборщика Купер показывается сразу; для курьера проводится прежний опрос.
- Фильтрация курьерских вариантов по способу передвижения, формату работы, частоте выплат и статусу карты.
- SQLite-статистика: запуски `/start`, уникальные пользователи, начало/завершение теста, просмотры агрегаторов и нажатия на кнопку перехода к регистрации.
- Повторное прохождение теста начинает новый проход и не использует старые ответы.

## Настройка BotHost

1. Загрузите файлы репозитория на GitHub.
2. Установите зависимости из `requirements.txt`.
3. Укажите команду запуска `python bot.py`.
4. Добавьте переменную окружения `BOT_TOKEN` с токеном Telegram-бота.
5. При необходимости задайте `CHANNEL_LINK` и `CHAT_LINK`.
6. В `aggregators.json` заполните `description` и `referral_link` для нужных агрегаторов. Для сборщика Купера используется та же запись Купера и та же ссылка, что и для курьера.

`stats.db` создаётся автоматически при первом запуске. Не загружайте файл базы данных в GitHub.

## Важно про статистику кликов

Telegram не сообщает боту, был ли нажат URL-кнопка и завершилась ли регистрация на внешнем сайте. Поэтому событие `registration_link_click` записывается при нажатии отдельной кнопки «Я перехожу к регистрации». Это фиксирует намерение пользователя перейти, а не подтверждённую регистрацию.

## Данные теста

Для заблокированной карты остаются только варианты, где `third_party_card` установлен в `true`. Перед использованием проверьте действующие правила конкретного партнёра: возможность выплаты на чужую карту зависит от условий партнёра. Для работы может требоваться статус самозанятого — это отмечено в данных агрегатора.
